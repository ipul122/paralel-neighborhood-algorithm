# Neighbourhood Algorithm – Appraisal Stage (Python)

This repository contains a Python implementation of the **appraisal stage** of the Neighbourhood Algorithm (NA), adapted from:

https://github.com/auggiemarignier/neighpy/blob/main/neighpy/appraise.py

The appraisal stage evaluates the ensemble of models produced during the search stage and estimates the posterior distribution without additional forward model evaluations.
